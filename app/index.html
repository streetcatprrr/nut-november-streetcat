Vet-certified donations

Ecash that nobody can spend until the clinic certifies the operation · Everything runs in this page · Nothing is uploaded anywhere

Each one sees only its own part of this page. Nothing is sent anywhere.

Pay from any Lightning wallet. The page receives your sats as ecash that is already locked: only Streetcat + the clinic together can spend it, or you alone after the deadline.
How it works: your sats become a locked token at the campaign's mint. Keep the receipt private: it holds the refund key for this donation (a new key every time; this browser keeps a copy). Then send the locked token to Streetcat (it is useless to anyone until the clinic signs) and follow it on the campaign's status page. If the clinic never certifies before the deadline, come back to Donor: refund: you can take the sats back as ecash or straight to a Lightning wallet.

The mint will only accept this if the clinic's signature is on it. The result is a plain token for Streetcat's wallet.
Works only after the campaign deadline, and only if the clinic never certified. Before that the mint refuses.

Keys live only in this browser (localStorage). Back them up. A public key is what you publish; a private key is what signs. Donors get a new refund key for every donation: it is in that donation's receipt and kept here as a backup. A new or imported clinic or Streetcat key never deletes the one before: it is kept here, so tokens locked to it can still be signed from this browser. Keys stay per browser and per address: another browser, a private tab or an app's built-in browser has its own.
